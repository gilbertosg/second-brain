# AI for Friends Course × Career × Contribution — Cross-Pillar Synthesis

Gil created and taught an AI-literacy course ("AI for Friends") outside any single pillar's existing OKR structure. This map traces where that course intersects L3 (career) and L7 (contribution), and flags one compliance-relevant finding that reaches back into how Gil personally uses AI tools at Blue Origin.

---

## 1. The Core Model: One Artifact, Three Pillar Effects

```
L4 Input (Course creation + delivery)
──────────────────────────────────────────────────────────
Building 3-module AI curriculum   →   L4: "4 AI/side projects" OKR credit
Teaching it to friends            →   L3: Agent Award KR evidence
                                       L3: Principal-promotion AI-differentiator
Finished course material          →   L7: ready-made blog/video content
                                       (fills the "what do I write about" gap)
```

**Key finding:** unlike most L4 inputs, which feed L3 *indirectly* through skill-building, this course is direct L3 evidence — it is a demonstrated, teachable AI capability, which is exactly what an "Agent Award" nomination needs to show. It simultaneously satisfies an L4 OKR and produces L7-ready output without additional Saturday-morning work, since the material already exists.

---

## 2. L4 → L3: Agent Award and Promotion Evidence

`L3-Career/_pillar.md` names the Agent Award KR as a signal that "AI/automation work is a differentiator for the promotion case," but the pillar's current book-notes and topic maps treat this mostly in the abstract (ML courses taken, projects planned). Creating and delivering a full AI-literacy curriculum — including a working Claude Code onboarding guide — is concrete, demonstrable evidence rather than a course-completion certificate.

**Additional finding:** Module 3 of the course (`course-ai-for-friends-module3-claude-code.md`) contains an explicit confidentiality warning: personal Claude Pro has no corporate data agreement, admin oversight, audit logs, or retention controls, and running client files, employee records, or privileged material through it requires employer IT/Legal approval. Gil wrote this guidance for his friends, but it applies equally to his own use of Claude Code on anything Blue-Origin-adjacent. This is flagged as a personal compliance action item, not just course content — see Open Gaps below.

---

## 3. L4 → L7: The Teaching Loop, Now With a Real Instance

`02-Indexes/topic_maps/career-productivity-crossmap.md` (Section 8) already identified an unwired "L4 → L7 Teaching Loop": every L4 learning output should become an L7 content output, but at the time no mechanism connected them. The AI for Friends course is the strongest instance of that loop found so far — it is already in a teachable, structured format (module notes with tables and frameworks), which lowers the marginal cost of turning it into L7 content close to zero.

| L4 Artifact | Possible L7 Output |
|---|---|
| Module 1 (COSTARS framework, prompting patterns) | 1 blog post: "Five prompts that cover 90% of my AI-for-work usage" |
| Module 3 (Claude Code onboarding) | 1 YouTube video walkthrough, or 1 TPM Samurai post on AI tooling for program managers |
| The course as a whole | 1 "failure post" candidate if any part of teaching it didn't go as planned (fits the 6 failure-posts KR) |
